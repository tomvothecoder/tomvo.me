# Tom Vo Strength — Aligned Logo Package

This package contains the approved PNG logo files and SVG files that are aligned directly to the PNG artwork.

Important note:
- The SVG files in this package are exact SVG wrappers embedding the approved PNG artwork.

- Use the PNGs when you want straightforward image placement.
